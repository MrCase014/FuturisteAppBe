# 07 — PARCOURS UTILISATEURS

> Un parcours n'est pas une liste d'écrans : c'est **ce que la personne vit**.
> Si un parcours n'a pas de sens raconté à voix haute, aucun écran ne le sauvera.

---

## Parcours 1 — Le coach prépare et anime sa séance (LE parcours central)

**Personnage :** Aminata, coach U11, 28 ans, travaille la journée, prépare ses
séances le soir sur son téléphone, anime le mardi et le jeudi à 17 h.

### Mercredi soir, 21 h, chez elle

```
1. Elle ouvre l'app → Tableau de bord coach
   « Prochaine séance : jeudi 17 h — U11 Filles A — pas encore préparée »

2. Elle tape « Préparer »  →  SESSION STUDIO

   ┌─────────────────────────────────────────────┐
   │  ÉTAPE 1 / 4   Le cadre                     │
   │  Catégorie  U11 ▾    Joueurs  16            │
   │  Durée      90 min    Niveau  Intermédiaire │
   └─────────────────────────────────────────────┘
   ┌─────────────────────────────────────────────┐
   │  ÉTAPE 2 / 4   L'objectif                   │
   │  Domaine : INTELLIGENCE                     │
   │  Thème   : Occupation des espaces           │
   │                                             │
   │  💡 6 joueuses de ce groupe ont un objectif │
   │     actif « Prise d'information ».          │
   │     → Le travailler aussi ?    [Oui] [Non]  │
   └─────────────────────────────────────────────┘
```
👉 **C'est ici que la boucle se ferme.** L'application ne propose pas des exercices
au hasard : elle propose ce dont *ces* joueuses ont besoin cette semaine.

```
   ┌─────────────────────────────────────────────┐
   │  ÉTAPE 3 / 4   La séance proposée           │
   │  ① 10' ACCUEIL        Jeu libre au ballon   │
   │  ② 15' ACTIVATION     Éveil + coordination  │
   │  ③ 15' TECHNIQUE      Contrôle orienté 🎥   │
   │  ④ 20' JEU DE POSITION Rondo 4v4+3 🎥      │
   │  ⑤ 20' SITUATION      6v6 zones de couloir  │
   │  ⑥ 10' RETOUR AU CALME Étirements + débrief │
   │                                             │
   │  [↑↓ déplacer] [✏️ modifier] [🔄 remplacer] │
   └─────────────────────────────────────────────┘

3. Elle remplace l'exercice ④ (elle n'aura que 8 plots)
   → Le filtre « matériel » lui propose 3 alternatives équivalentes.

4. ÉTAPE 4 / 4 — récapitulatif : matériel total, dimensions, objectifs.
   Elle tape « Valider » puis « 📥 Rendre disponible hors ligne ».
   → Exercices, schémas et 2 vidéos se téléchargent sur son téléphone.
```

### Jeudi 16 h 55, sur le terrain, sans réseau

```
5. Elle ouvre l'app → bandeau « Séance prête · Mode hors ligne ✓ »
   → « Prise de présence » : 16 photos en grille, 1 tap = présent.
     Fatou est absente → 2ᵉ tap = absente → motif (facultatif).

6. Elle lance le MODE TERRAIN :

   ┌───────────────────────────────────────┐
   │ ② ACTIVATION            ⏱ 12:34       │
   │                                       │
   │      [ SCHÉMA 2D ANIMÉ EN GRAND ]     │
   │                                       │
   │ 🎯 Éveil + coordination               │
   │ 👁 Regarde avant de recevoir          │
   │    Corps orienté vers le jeu          │
   │                                       │
   │  ⏮        ▶️ / ⏸        ⏭            │
   └───────────────────────────────────────┘

   → Écran toujours allumé, gros boutons, une seule main.
   → Elle peut noter une observation rapide sur une joueuse en 2 taps,
     sans quitter le chronomètre.
```

### Jeudi 18 h 40, dans la voiture

```
7. « Évaluer la séance » (5 minutes chrono)

   ÉTAPE A — Le groupe
   Objectif de séance atteint ? ●●●○○   Engagement global ? ●●●●○

   ÉTAPE B — Les joueuses (défilement)
   ┌──────────────────────────────────────┐
   │ 📷 Sekou D.                          │
   │ Engagement  1 2 [3] 4 5              │
   │ Objectif « Prise d'info » travaillé ? │
   │        ✅ Oui — ●●●○○                 │
   │ 💬 « Regarde rarement avant de       │
   │      recevoir, mais a progressé sur  │
   │      le côté droit »                 │
   │                                      │
   │  [ ⟶ Transformer en objectif ]       │
   └──────────────────────────────────────┘

   → Elle n'évalue pas les 16 joueuses. Elle en évalue 5 ou 6.
     L'app lui montre en premier celles qui n'ont pas été évaluées
     depuis le plus longtemps. Sur une saison, tout le monde est couvert.

8. Retour à la maison, le Wi-Fi revient :
   « ✓ 6 évaluations et 16 présences synchronisées »
```

**Ce qui rend ce parcours viable :** préparer une séance prend **6 minutes**,
évaluer en prend **5**. Au-delà, un coach bénévole abandonne l'outil — quelle
que soit sa qualité. Le temps est la contrainte de conception numéro un.

## Parcours 2 — Le directeur pilote l'académie

**Personnage :** Le fondateur, tous les lundis matin, sur ordinateur.

```
1. Tableau de bord
   ┌──────────┬──────────┬──────────┬──────────┐
   │ 147      │ 7        │ 9        │ 84 %     │
   │ joueurs  │catégories│ coachs   │ présence │
   └──────────┴──────────┴──────────┴──────────┘

   🔔 ALERTES (3)
   ⚠️ U15 : présence tombée à 61 % (−18 pts en 3 semaines)
   ⚠️ 4 joueurs U13 sans évaluation depuis plus de 30 jours
   ⚠️ 7 objectifs dépassent leur date cible

2. Il clique sur l'alerte U15
   → Détail équipe : le creux date de la rentrée scolaire.
   → Il écrit une annonce aux parents U15 en 3 clics.

3. Onglet Statistiques → filtre « U11 · 3 derniers mois »
   → Radar collectif : INTELLIGENCE à 2,1 / 5, le plus bas des 8 domaines.
   → Il ouvre « Méthodologie U11 » et renforce la prise d'information
     dans les compétences prioritaires.

4. Effet en cascade, sans action supplémentaire :
   → Le Session Studio de tous les coachs U11 remonte
     automatiquement les exercices d'INTELLIGENCE dès la semaine suivante.
```

👉 **Le directeur pilote la méthodologie, pas les séances.** Il change une règle,
elle se propage à toute l'académie. C'est ce qui distingue un centre de formation
d'une addition d'entraîneurs.

## Parcours 3 — Le parent suit son enfant

**Personnage :** M. Diallo, père de Sekou (11 ans), sur son téléphone, le soir.

```
1. Il reçoit une notification :
   « Sekou a débloqué le badge 👁️ Scanner ! »

2. Il ouvre l'app → Accueil parent
   ┌──────────────────────────────────────┐
   │ 📷 Sekou Diallo · U11 Filles A       │
   │ Prochaine séance : mardi 17 h        │
   │ Présence ce mois : 8/9  (89 %)       │
   │                                      │
   │ 🎯 CE QUE SEKOU TRAVAILLE            │
   │ « Regarder autour de soi avant       │
   │   de recevoir »          ▓▓▓▓▓░░ 60 %│
   │                                      │
   │ 💡 COMMENT L'AIDER À LA MAISON       │
   │ Dans le jardin, demandez-lui de dire │
   │ une couleur que vous montrez pendant │
   │ qu'elle contrôle le ballon.          │
   └──────────────────────────────────────┘
```

👉 **Le parent ne voit jamais une note brute.** Il voit un **objectif**, une
**progression** et une **action concrète**. C'est une décision de produit, pas
une limitation technique : afficher « 2/5 en technique » à un père transforme
un outil de développement en outil de pression.

```
3. Onglet FUTURISTE FAMILY
   → Sommeil · Nutrition · École · Comportement pendant les matchs
   → Article : « Que dire à votre enfant dans la voiture après un match »

4. Sekou est malade → « Signaler une absence » → le coach est notifié.
   C'est la SEULE action d'écriture autorisée au parent.
```

## Parcours 4 — Le joueur

**Sekou, 11 ans, sur le téléphone de sa mère, 20 minutes par semaine.**

```
┌────────────────────────────────┐
│   Salut Sekou ! 👋             │
│                                │
│   🎯 MON NEXT LEVEL            │
│   ┌────────────────────────┐   │
│   │ 👁️ Regarder avant       │   │
│   │    de recevoir          │   │
│   │    ▓▓▓▓▓▓░░░░  60 %     │   │
│   │    🎥 Regarde comment   │   │
│   └────────────────────────┘   │
│                                │
│   🏅 MES BADGES  (7)           │
│   ⚽ 🪄 👁️ 🧠 🔥 💪 ⭐          │
│                                │
│   📅 Prochaine séance          │
│      Mardi 17 h                │
└────────────────────────────────┘
```

Règles de conception pour l'espace joueur :
- **Jamais de classement entre joueurs.** Aucun. La comparaison détruit la
  progression individuelle et fabrique de l'abandon.
- **Les badges récompensent le développement**, pas les buts ni les victoires.
- **Interface SIMPLE pour U7-U11** : pictogrammes, 3 informations maximum.
- **Interface COMPLÈTE à partir de U13** : radar, statistiques, PLAYER DNA.

## Parcours 5 — Un joueur entre à 6 ans et sort à 18 ans

C'est le parcours qui justifie l'existence du produit.

```
6 ans   U7    Inscription. Aucune évaluation chiffrée.
              Le coach note du qualitatif : « adore le ballon, timide au duel ».
              Pas de PLAYER DNA. Pas de statistiques. Badges plaisir uniquement.

8 ans   U9    Premières évaluations sur 8 compétences maximum.
              Premier objectif MY NEXT LEVEL : « oser dribbler ».

10 ans  U11   Évaluation sur les 8 domaines. Le radar apparaît.
              L'historique commence à dessiner une courbe.

12 ans  U13   PLAYER DNA activé (confiance suffisante : ~40 évaluations).
              « Profil : joueur de transition, tendance créateur ».
              Jeu de position, largeur, profondeur.

14 ans  U15   Intensité, vitesse, physique. Statistiques de match complètes.
              Objectifs co-construits avec le joueur, plus imposés.

16 ans  U16   Spécialisation progressive. Analyse vidéo de ses propres matchs.

18 ans  U18   📄 DOSSIER DE DÉVELOPPEMENT FUTURISTE
              12 ans de données : courbes, évaluations, matchs, objectifs
              atteints, vidéos clés. Exportable en PDF.
              → Pour un club, une université, une sélection.
```

👉 **Ce dossier de sortie est l'actif le plus précieux de l'académie.**
Aucune académie concurrente ne peut le produire sans 12 ans de données
structurées. C'est exactement pour ça que le schéma de base de données
(document 04) mérite qu'on y passe du temps **maintenant**.

## Parcours 6 — Premier démarrage de l'académie (le jour 1)

```
1. SUPER_ADMIN crée l'académie et le compte du directeur.
2. Le directeur se connecte → assistant de démarrage en 6 étapes :
   ① Logo et couleurs
   ② Catégories (les 7 sont pré-remplies, modifiables)
   ③ Domaines et compétences (référentiel FUTURISTE pré-rempli)
   ④ Coachs (invitations par e-mail)
   ⑤ Équipes
   ⑥ Joueurs (saisie manuelle ou import CSV)
3. Il coche les consentements parentaux à l'inscription.
4. La bibliothèque démarre avec 20 exercices FUTURISTE prêts à l'emploi.
5. Les coachs reçoivent leur invitation. Première séance préparée le soir même.
```

**Objectif mesurable :** une académie doit pouvoir être **opérationnelle en une
journée**. Si le démarrage prend deux semaines, le produit ne sera jamais adopté.
